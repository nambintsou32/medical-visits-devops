# Operational Runbooks

This directory contains procedures used to operate and recover the deployed system.

Planned runbooks:

- application deployment;
- deployment verification;
- rollback to a previous image;
- MySQL backup and restoration;
- failed pod diagnosis;
- K3s node failure;
- Longhorn volume recovery;
- Jenkins pipeline troubleshooting;
- credential rotation.

Each runbook will include:

1. purpose and scope;
2. prerequisites;
3. exact commands;
4. expected results;
5. rollback or recovery procedure;
6. validation criteria.

Runbooks are added only after their procedures have been tested successfully.
